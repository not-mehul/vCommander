--- Changelog ---
v3.0
- Revamped GUI, new frontend built with Flet
- Restructured backend to support long-term iteration
- Added Commission Tool
- Version check on startup with Github

v3.1
- (New feature) Sort the copy button for the invited users in alphabetical order
- (Bug fix) Updated the subdomain for vproresponse to vagent
- (Bug fix) Added LPR camera door linking to the commission tool

v3.2
- (New feature) Decommission tool deletes granular assets and entities: Access Groups, Access Levels, Schedules, Scenarios, Doors, Floors, Buildings, Visitor access, Alarm Systems, Alarm Partitions, Alarm Guards, Alarm Wired Inputs/Outputs and Site
- (New feature) Decommission tool CSV export shows the serial numbers alongside object ids wherever present.
- (New feature) Decommission tool now lists and deletes Access Station Pro devices and Sites (renamed if unable to delete)
- (New feature) Decommission progress is now collapsed into product categories.
- (New feature) Commission & Decommission Tool contain an option to cancel commissioning/decommissioning process.
- (New feature) Global keyboard shortcuts: Enter logs in, Esc backs out, Cmd/Ctrl-K jumps to Home, Cmd/Ctrl-, logs out
- (Bug fix) Alarms now creates a response, setting it to Self-monitored mode.
- (Bug fix) AI powered search and certain additional analytics also toggled on by default
- (Bug fix) Alarms Specialist Commission will now allow toggling face analytics, with the default toggled to True.
- (Bug fix) Alarms Specialist creates a General Keycode for the Instructor - 123456
- (Bug fix) Session timeout is now a fixed 30-minute window from login.

v3.3
- (New feature) Updated UI to be more consistent throughout the tool with a sidebar. Major UI revamp. Major Code Cleanup.
- (New feature) Kit A Added to the Database!
- (New feature) Decommission tool now lists and deletes Persons of Interest, Archives, Incidents, Visits, Visitors, and Alerts.
- (Bug fix) Updated Visitor Access Templates API call.
- (Bug fix) External API client refreshes its short-lived token on a 401/403 and retries, preventing "failed to authenticate" errors when the token expires mid-run.
- (Bug fix) Updated Flet from 0.28.3 to 0.85
- (Bug fix) Updated SMS Authenticator API to handle text messages correctly.

v3.4
- (New Feature) Incorporated AF64 Commissioning steps into ESS and ACSL.
- (New Feature) Split ACS into ACSL (Access Control Specialist - Lab) and ACSE (Access Control Specialist - Exam). ACSL incorporates the AF64 Commissioning and setup. ACSE inherits the original ACS flow.
- (New Feature) When adding users using the Invite Tool, by default users are also added to a 'All Participants' group. Can be toggled off during review.
- (New Feature) Input Validation for S/N, so it automatically fills in the correct XXXX-XXXX-XXXX format.
- (New Feature) Decommission the Access Controller after creating the Access Level to prevent accidental commissioning or errors if not paying attention to the tool's summary during setup.
- (New Feature) Several new endpoints added: group.create, group.add_members, org.allow_face_unlock, access_station_pro.create, access_station_pro.door.create, door.enable_face_unlock, door.mfa.card-code, door.mfa.face-card, door.mfa.face-code, schedule.create.mfa

v3.5
- Updated ACS Lab to create 'HQ' instead of 'Trainer-HQ'
- Updated AF64 Commissioning to disable DPI during setup
- Added Strobe Light Creation on the Alarm Panel Pin 1 during AS Commissioning
- (New feature) Commission claims all of a template's devices with one batch call and sets up cameras together
- (New feature) ACSL creates its door with the MFA modes in one call
- (New feature) Invite Tool adds participants to an 'All Participants' Command group and access group, reusing both on re-runs and adding only those not yet in them
- (New feature) Invites go out four at a time; people already in the org are reported instead of re-invited, and still join the group
- (New feature) Decommission uses only the internal API (no API key); Command Users and Persons of Interest are deleted with one call each, other categories four at a time
- (New feature) Decommission scan lists categories in parallel and sends each identical read once (about twice as fast)
- (Bug fix) Decommission revokes both Access Admin roles when it ends, including ones Command granted at a controller claim
- (Bug fix) Persons of Interest are deleted before Cameras (Command refuses the delete once the org has no cameras)
- (Bug fix) API key secrets are no longer written to the API call log
- (Bug fix) Strobe Light is on the panel's Output 1
- (New feature) ESS and AS add the Strobe Light (Output 1) to the Default Response's output devices; ESS now creates the strobe too
- (New feature) ESS creates the '[DO NOT TOUCH] AF64' access level on HQ Door, granted to 'All Participants' when that access group exists (the Invite Tool grants it otherwise)
- (New feature) ACSE: "Remove existing user permissions" (on by default) first strips every other user's organization, user management and site roles, keeping Org Admin
- (New feature) Invite Tool also adds participants to 'VCE Access Group' when the org has it (VSSL), and makes sure 'VCE Access Level' and '[DO NOT TOUCH] AF64' grant their group
- (Bug fix) Removed a fixed 3-second wait after creating a building
